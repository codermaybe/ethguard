## 观察摘要（人工核对，非兼容结论）

- chainId / net_version / blockNumber：可用来源全部一致（0x1 / 1 / 同高）。
- latest header：三源同 hash、同 26 字段集合；字段值一致。
- latest full block：同 hash、293 笔交易、hash 序列一致。llamarpc 与 publicnode
  在键排序归一化后完全相等；ankr 的每笔交易多一个 `blockTimestamp` 字段
  （厂商扩展，未纳入标准字段集）。
- withdrawals：三源内容相等，仅 JSON 键顺序不同（表示差异，非内容差异）。
- finalized：三源同高（0x18bd436）同 hash。
- 失败形态覆盖：HTTP 525（llamarpc run1）、JSON-RPC -32000 认证错误（ankr run1）、
  非 JSON 正文（merkle）。错误分类（http / malformed_json / jsonrpc）按预期落档。

## 边界

本目录是观察记录，不是兼容性验收：来源为公共免费端点，未覆盖历史分叉、
裁剪节点、pending 语义与 typed 交易全类型。样本仅覆盖 latest/finalized 头与
完整块、gasPrice、syncing；状态读取、logs、feeHistory、eth_call 未采集。
